## Overview

**rst-renderer** is a TypeScript library that parses reStructuredText (RST) into a
unified AST and renders it to multiple output formats.

### Quick Start

```bash
pnpm add @seqyuan/rst-renderer
```

```ts
import { renderRst } from '@seqyuan/rst-renderer'

const html = renderRst(`Hello
=====

This is **bold** and *italic* text.

- item 1
- item 2
`)
```

### Packages

| Package | Description | npm |

| `@seqyuan/rst-renderer` | Core: parser + HTML/React/Markdown renderers + template engine | `pnpm add @seqyuan/rst-renderer` |
| `@seqyuan/rst-cli` | CLI: `rst-render input.rst -o out.html` | `pnpm add -g @seqyuan/rst-cli` |
| `@seqyuan/vite-plugin-rst` | Vite: `import html from './doc.rst'` | `pnpm add -D @seqyuan/vite-plugin-rst` |

### Architecture

```
RST Source
    │
    ▼
┌─────────────┐
│   Parser    │  ← builtin parser / rst-compiler adapter
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Unified AST │  ← 40+ node types (Document, Section, Paragraph, Table...)
└──────┬──────┘
       │
       ├──→ HTML Renderer    (11 directive plugins, Shiki, KaTeX)
       ├──→ React Renderer   (custom component mapping)
       └──→ Markdown Renderer (GFM tables, heading offset)
```

### Usage Scenarios

**Documentation sites** — Render RST documentation to HTML at build time.

```ts
import { renderRst } from '@seqyuan/rst-renderer'
import fs from 'node:fs'

const rst = fs.readFileSync('README.rst', 'utf-8')
const html = renderRst(rst)
```

**Bioinformatics reports** — Generate HTML reports from Jinja2 RST templates.

```ts
import { renderRstTemplate } from '@seqyuan/rst-renderer'

const template = fs.readFileSync('report.rst.j2', 'utf-8')
const html = renderRstTemplate(template, {
  samples: [{ name: 'CTRL', metrics: { cells: 5000 } }],
  version: '7.2.0',
})
```

**React apps** — Render RST content as React components.

```tsx
import { ReactRenderer } from '@seqyuan/rst-renderer/react'

const renderer = new ReactRenderer({
  components: {
    Section: ({ node, children }) => (
      <section className="my-section">
        <h2>{node.title}</h2>
        {children}
      </section>
    ),
  },
})
```

**Vite projects** — Import .rst files directly.

```ts
// vite.config.ts
import rst from '@seqyuan/vite-plugin-rst'
export default { plugins: [rst()] }

// your-component.tsx
import { html } from './doc.rst'
```
