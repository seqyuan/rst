## Gallery / Showcase

See the rendered output of common RST patterns.

### Basic Text

```rst
Hello World
===========

This is a paragraph with **bold**, *italic*, and ``inline code``.

Another paragraph with a `literal` and *nested **markup***.
```

**Renders as:**

<div className="border rounded-xl p-6 my-4 bg-fd-card">
  <h2 id="hello-world">Hello World</h2>
  <p>This is a paragraph with <strong>bold</strong>, <em>italic</em>, and <code>inline code</code>.</p>
  <p>Another paragraph with a <code>literal</code> and <em>nested <strong>markup</strong></em>.</p>
</div>

### Sections & Lists

```rst
========

-----------------

* HTML rendering with 11 directive plugins
* React component tree generation
* Markdown conversion with GFM tables

Installation
------------

3. Enjoy!
```

**Renders as:**

<div className="border rounded-xl p-6 my-4 bg-fd-card">

  <ul>

  <ol>
    <li>Install the package</li>
    <li>Import and render</li>
    <li>Enjoy!</li>
  </ol>
</div>

### Code Blocks

```rst
Usage Example
=============

.. code:: typescript

   import { renderRst } from '@seqyuan/rst-renderer'

   const html = renderRst(rstSource)
   console.log(html)
```

**Renders as:**

<div className="border rounded-xl p-6 my-4 bg-fd-card">
  <h2 id="usage-example">Usage Example</h2>
  <pre><code className="language-typescript">{`import { renderRst } from '@seqyuan/rst-renderer'

const html = renderRst(rstSource)
console.log(html)`}</code></pre>
</div>

### Admonitions

```rst
.. note::

   This is a note admonition with important information.

.. warning::

   This is a warning! Pay attention to this.

.. tip::

   Pro tip: use rst-renderer for all your RST needs.
```

**Renders as:**

<div className="border rounded-xl p-6 my-4 bg-fd-card space-y-4">
  <div className="border-l-4 border-blue-500 bg-blue-50 dark:bg-blue-950/30 p-4 rounded-r">
    <p className="font-semibold text-blue-700 dark:text-blue-300">Note</p>
    <p className="text-sm">This is a note admonition with important information.</p>
  </div>
  <div className="border-l-4 border-yellow-500 bg-yellow-50 dark:bg-yellow-950/30 p-4 rounded-r">
    <p className="font-semibold text-yellow-700 dark:text-yellow-300">Warning</p>
    <p className="text-sm">This is a warning! Pay attention to this.</p>
